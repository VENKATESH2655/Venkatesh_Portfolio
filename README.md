# Venkatesh S — Developer Portfolio

A modern, responsive, interactive personal portfolio website built with pure **HTML5, CSS3, and Vanilla JavaScript**.

## Included Files
- `index.html` — Semantic portfolio markup featuring Hero Terminal, Experience Timeline, AI/ML Projects, Skills Matrix, Education, Certifications, and Contact section.
- `style.css` — Glassmorphism UI styling, responsive grids, custom animations, and dark-mode theme.
- `script.js` — Interactive particle network canvas, typewriter role switcher, cursor glow, and mobile menu toggle.

## How to Deploy on Vercel (Zero Build Setup)
1. **Unzip** this folder (`venkatesh-portfolio.zip`).
2. **Option A (Drag & Drop / CLI):**
   - Install Vercel CLI (`npm i -g vercel`), open your terminal inside the unzipped folder, and run `vercel`.
3. **Option B (GitHub):**
   - Push the unzipped files (`index.html`, `style.css`, `script.js`) to a GitHub repository.
   - Import the repository in [vercel.com](https://vercel.com) and click **Deploy** (leave Framework Preset as *Other*).
